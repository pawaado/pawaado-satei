# パワアド査定ツール

GitHub Pages で公開している査定ツールの保守メモです。

## ファイルの役割（正本）

機能を直すときは、まずこの表の「正本」だけを変更します。同じ内容を別ファイルから上書きしない方針です。

| ファイル | 役割 |
|---|---|
| `index.html` | メイン画面のHTML、**使い方本文の正本** |
| `style.css` | メイン画面の見た目 |
| `data.js` | アカデミー、ジョブ、基本能力上限、特殊能力、超特殊能力、耐性効果・査定倍率などのゲームデータ正本 |
| `script.js` | 入力状態、複数経験点パターン、訓練後の付与予定経験点、計算開始、結果表示 |
| `photo_import.js` | 能力アップ／能力データ／訓練画像の判定・画像認識 |
| `academy_runtime.js` | アカデミー／ジョブ固有処理、双剣士専用通常攻撃、計算Worker連携 |
| `resistance_patch.js` | 査定が変動する超特殊能力の選択・追加削除・下位能力連動、耐性・HP依存査定のWorker連携。見た目は `style.css` を正本にする |
| `pawaado_worker.js` | 最大査定を求める計算Worker本体 |
| `pawaado_worker_resistance.js` | 耐性込み計算のWorkerエントリ |
| `rankings.html` | 査定効率ランキング画面 |
| `assets/` | 画像認識用の固定画像 |
| `vendor/ocr/` | OCRライブラリ・認識データ |

## 保守ルール

1. **同じ表示文言を複数ファイルから書き換えない。** 使い方は `index.html`、ゲームデータは `data.js` を正本にする。
2. 新しい機能のためだけに `*_patch.js` や `*_v2.js` を増やさず、役割が一致する既存ファイルへ追加する。
3. 画像認識テンプレートは `photo_import.js` に集約する。画像を受領して追加した能力は、その場でテンプレート登録まで行う。
4. 通常入力の○／◎は元画像の記号形状と同名○／◎テンプレートで判定する。金色セルは超特殊能力として別系統で判定する。
5. 超特殊能力が確認できた場合、対応する下位◎は取得済みとして補完する。
6. 訓練画像が複数ある場合は、各訓練後の経験点をパターンA/B…として扱う。「訓練後の付与予定経験点」は各パターンへ共通加算して比較する。
7. 変更後はキャッシュ用の `?v=` を更新し、古いJS/CSSがSafariに残らないようにする。
8. 不要になった互換ファイルは参照元を確認してから削除する。削除前にはバックアップブランチを作る。
9. `photo_import.js` の `matchesTemplate(image,'name',...)` は `assets/name.png` を動的参照する。`.png` の直書きが見つからないだけで未使用と判断しない。

## 画像入力の基本

- 「能力アップ」画面：1枚を前提に、文字表示からジョブと現在経験点を読み取る。ジョブは能力データのアイコン判定よりこちらを優先する。
- 「能力データ」画面：アカデミー、キャラ右上のジョブ固有マーク、基本能力、取得済み特殊能力、査定が変動する超特殊能力を読み取る。
- 「訓練」画面：現在経験点と増加経験点を読み取り、複数枚なら経験点パターンを作る。「能力データ」＋「訓練」が揃えば「能力アップ」は不要。
- 基本能力は能力データ側を正本とし、能力アップ側からは確定しない。
- 双剣士専用「通常攻撃」は通常特殊能力の「通常攻撃○／◎」と別管理。
- 特殊能力が本当に空の能力データ画面では、特殊能力読取エラーを出さない。

## 関連ファイルの自動確認

- 作業時の継続ルールは `AGENTS.md`。関連ファイルの確認をユーザーが毎回指定する必要はありません。
- `node scripts/check-integrity.cjs`：構文・参照ファイル・動的画像・版番号・耐性Workerの実起動を確認。
- `node scripts/check-integrity.cjs --base <変更前コミット>`：変更したJS/CSSの参照元でキャッシュ版が更新されているか確認。
- `node --test tests/*.test.cjs`：画像入力・ランキングの回帰テスト。
- GitHubのpush/PRで `Related-file integrity` を実行。失敗は修正してから完了扱いにする。このワークフロー単独でPagesの公開を停止するものではありません。
