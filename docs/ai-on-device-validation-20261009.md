# パワアド画像読み取り：端末内AI検証（2026-10-09）

この記録は実験専用。通常の査定ツールのOCR・入力ロジックには適用しない。

## 使用データと検証方法
- これまでユーザーが提供したゲーム画像41枚を手元で確認。そのうち実際に手作業で正解を確定できた画像8枚から、96マスをラベル付け。
- ラベル：○29、◎33、○◎なし34。
- 同一キャラクター・類似スクロール画像は同じグループにし、グループごとに学習から外して評価（6グループ）。
- 20×20グレースケール特徴＋3分類の線形モデル。外部API費用は不要。
- 「現行」の比較対象は `markShapeByImage` だけのPython移植であり、文字OCR・セル全体テンプレート比較まで含んだ最終処理ではない。

画質を変えた画像を学習に加えた場合も、原画像の誤判定が増えるなど、現時点では安定せず。**確信度だけで誤判定を防げるとは限らない。**

## 採用を判断するための残課題
1. 文字の読み取り漏れも含めて、既存の最終OCR結果との対応を取ったデータで比較する。
2. 記号なしの多様な名称、金色セル、文字の重なり、端末別解像度の正解画像を増やす。
3. 未学習のスクリーン・ジョブ・別端末で確認し、誤って「取得済」にしない安全条件を設ける。
4. 実際の端末で処理時間・メモリ・Safariでの互換性を測定する。

**結論：実験を続ける価値はあるが、現時点で本番OCRをAIで置き換えるのは危険。**
